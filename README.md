# Linux Monitoring v1 — Bash

Учебный проект Школы 21: Bash-скрипты для вывода системной информации и исследования файловой системы.

## Реализация

| Часть | Назначение | Файлы |
| --- | --- | --- |
| 01 | Приём текстового аргумента, отклонение чисел | [src/01](src/01) |
| 02 | Сбор параметров системы и сохранение отчёта по запросу | [src/02](src/02) |
| 03 | Цветной вывод с проверкой четырёх параметров | [src/03](src/03) |
| 04 | Цветовая схема из config.conf и значения по умолчанию | [src/04](src/04) |
| 05 | Число и типы файлов, крупнейшие файлы и каталоги | [src/05](src/05) |

## Запуск

Скрипты сбора информации рассчитаны на Linux: используются `/proc`, iproute2 и GNU-утилиты. Нужны Bash 4+, Python 3 и стандартные утилиты Ubuntu.

Из корня репозитория:

```bash
# Текстовый аргумент
bash src/01/main.sh "hello world"

# Системная информация; в конце будет вопрос о сохранении
bash src/02/main.sh

# Фон/текст для первого и второго столбца
bash src/03/main.sh 1 2 3 4

# Схема из src/04/config.conf
bash src/04/main.sh

# Анализ выбранного каталога; завершающий / обязателен
bash src/05/main.sh /var/log/
```

Цвета: `1` — white, `2` — red, `3` — green, `4` — blue, `5` — purple, `6` — black. Цвет текста и фона одного столбца должен различаться.

## Проверки

В этой ветке добавлены первые автоматические проверки:

```bash
python3 -m unittest discover -s tests -v
find src -type f -name '*.sh' -print0 | xargs -0 -n 1 bash -n
shellcheck -x -P SCRIPTDIR src/01/main.sh src/01/check_param.sh src/05/validate.sh
```

GitHub Actions запускает проверку синтаксиса всех Bash-файлов, ShellCheck выбранных модулей и 8 тестовых методов с дополнительными сценариями. Тестами обнаружена и исправлена ошибка буквального вывода аргументов `-n` и `-e`.

[Как устроены тесты и CI](docs/ci.md). Проверки поведения пока покрывают первую часть и валидатор пути пятой части. Сбор метрик, цветовые схемы и формирование файлового отчёта ещё не покрыты функциональными тестами.

## Ограничения

Полный запуск на macOS не поддерживается из-за Linux-зависимостей; отдельные тесты работают на macOS. Вывод файлового отчёта и обработка нестандартных имён файлов требуют дальнейшей проверки. Это учебные скрипты, а не система постоянного мониторинга; Prometheus/Grafana моего homelab относятся к отдельному стенду.
